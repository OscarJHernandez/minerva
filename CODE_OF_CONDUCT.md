# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(licensed CC BY 4.0). Read it at that address; it applies to all project spaces: issues, pull
requests, discussions and any place where someone represents the project.

In short: be respectful and constructive, welcome people of every background and level of experience,
accept criticism of ideas gracefully, and do not harass, demean or exclude anyone. Maintainers may
remove contributions and restrict participation that violate these expectations.

## Reporting

Report conduct concerns privately to the maintainers through a private GitHub security advisory
on this repository (select "conduct concern" in the title), or via the contact address the
maintainers list in the repository profile.
